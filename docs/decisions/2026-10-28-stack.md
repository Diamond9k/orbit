# Stack: Python, FastAPI, SQLite, Bootstrap, self-hosted

Date: 2026-10-28

Orbit runs as one Python process on one ordinary machine. SQLite is the database, one file
on disk. Pages are Jinja2 templates on a vendored copy of Bootstrap 5. No cloud database,
no hosting platform, no CDN. Stripe is the one outside service, per transaction.

Why: the whole point of Orbit is not depending on datacenters. Orbit does the light work
(a list and a ledger), so one small machine is enough for a long time. Hosts do the heavy
work, and that scales by adding hosts. Fewer parts, fewer errors.

Rejected: Supabase and Vercel (paid cloud, contradicts the thesis), a zero-dependency
Python server (not fit for production), React or any build step (complexity for no gain).
