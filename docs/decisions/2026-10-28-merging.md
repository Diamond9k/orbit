# Branches merge themselves when green

Date: 2026-10-28

A branch merges into main when two things are true: the tests pass on GitHub, and the critic
found nothing. Cooper does not merge by hand and does not want to. Cooper can revert anything.

How: the swarm script pushes a branch under `build/` only when the critic says "Nothing
found". The GitHub workflow runs the tests on every push. For a green `build/` branch it opens
a pull request and turns on auto-merge. Branches the critic flagged are pushed under
`review/` and wait for a fix, never merging on their own.

Why: the goal needs the loop to run without a person in it. The locks that matter are the
tests, the critic and the revert, not a click.

Needs once in GitHub settings: allow auto-merge on the repo, and protect main with the
"tests" check required.
