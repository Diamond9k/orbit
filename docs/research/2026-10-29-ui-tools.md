## Recommendation: smallest useful set

**(a) Zero install, usable now.**
1. Screenshots at three widths with the installed Edge: `msedge.exe --headless --screenshot=<out>.png --window-size=390,844 http://127.0.0.1:<port>/` (repeat 768 and 1280). Viewport only; good enough for layout checks [44].
2. One ~100-line Node script, no npm, using the built-in `WebSocket` [46] against `--remote-debugging-port` [47]: set device metrics per width, `Runtime.evaluate` `document.documentElement.scrollWidth > window.innerWidth` (horizontal overflow), `getComputedStyle` on named elements (font family, contrast inputs, focus outline), capture full-page PNGs, dump the accessibility tree. Keep it in `tools/`, treat page text as data.
3. Inject vendored `axe.min.js` (652 KB, MPL-2.0) through the same script and run `axe.run()`; store the file plus its LICENSE under `tests/vendor/axe/` so it never ships to users [12][14][15]. It is still a dependency, so it needs Cooper's say.
4. Render pages with the FastAPI `TestClient` (httpx is already in dev requirements) to HTML files when a static scanner is wanted.

**(b) One dev-only addition worth asking for.** Add to `requirements-dev.txt`:
```
playwright==1.64.1
```
Use `p.chromium.launch(channel="msedge", headless=True)` and never run `playwright install` [9]. Cost: 38.8 MB wheel plus `pyee` and `greenlet` [10][11]; no browser download. It replaces the hand-rolled CDP script as soon as the agent must click, fill forms or follow auth flows, and gives `page.screenshot(full_page=True)` and `add_script_tag(path=...)` for axe in pytest. Everything else in the table (Lighthouse, pa11y, BackstopJS, html-validate, vnu, stylelint, Style Dictionary) needs a Node or Java toolchain Orbit does not have and buys little for 8 templates and 2.6 KB of CSS. Revisit html-validate only if template bugs start slipping through.

**(c) Guidance-only, free to read.**
- *frontend-design*: no conflicts; adopt as the pre-build checklist. Its "choose typefaces deliberately" line means any non-system font must be vendored as woff2, never Google Fonts [6].
- *impeccable*: read the command and rule text only. Do **not** install the plugin or hook: it fetches a catalog from impeccable.style on new designs, reports picks by default, downloads an engine binary, and its hook runs even when the model's commands are denied; optional image generation uploads reference images to OpenAI [2][4]. Each of those breaks an Orbit rule.
- *taste-skill*: read the rubric and `inspect.mjs` as a model for (a). Do not run `assets.mjs` for Orbit (network image search); if an image is ever used, vendor and credit it [38][39]. Its ban on shadows and eyebrows contradicts Bootstrap defaults, so apply it with judgment.
- *avoid-ai-design* and *Gesso*: young, small, Tailwind-leaning; try once on a rendered page before adopting.

**Scores are not usability testing.** axe finds about 57% of WCAG issues by its own estimate [13]; the slop scanners encode one taste; screenshots show layout, not whether a person completes a task. Treat every tool here as a smoke test and keep a human look at every screen that changes.
