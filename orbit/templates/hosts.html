How a machine joins
  1. Add the machine here: a name, its GPU and the GPU memory. You get a private token.
  2. Run the host program on that machine with the token. It only dials out, so a home router needs no changes.
  3. Start a model from any browser. The program loads it with llama.cpp and tells Orbit when it is ready.
  4. The model runs on your machine until you stop it. Nobody else can start a model on it.
