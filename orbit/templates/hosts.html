How hosting works
  1. List a machine: name, GPU, memory, your price per hour. You get a private token.
  2. Run the host program with that token. It only dials out, so a home router needs no changes.
  3. When a user starts a session, the program loads the model and says ready. The clock starts then.
  4. You earn for every minute used. Orbit keeps a share of each session and shows it in the ledger.
