About Orbit

Any open model, on any computer you own, with no one in the middle.

Open models are free. If you own the hardware, running one should cost nothing and should send your words to no company. Orbit makes that as easy as opening a browser tab. It is a passion project, not a business.

Why it is free

A fee would contradict the point.

People self-host to stop paying a toll for something that runs on their own machine, and to keep their data out of other hands. A project that charged for that would stand against its own reason to exist. So Orbit has no price, no credits, no ads and no paid tier. It does not rent out anyone's computer. The code is open source under Apache 2.0.

The relay is the small web app that passes messages between your browser and your machine. One gap is open: both keys travel through the relay, so a dishonest relay could swap them, and nothing checks for that yet. Two things close it. Run the relay yourself, which takes one command. Or wait for the fingerprint check, which is next on the list. Details: docs/PRIVACY.md.

The rules

What Orbit holds to.

  1. Self-hosting only. Your models run on machines you own. No compute is rented, in either direction.
  2. Free. No fee, no credits, no ads, no paid tier.
  3. The relay cannot read. It passes sealed envelopes and deletes them when the session ends.
  4. No promises, no claims. Unknown shows as unknown, never as a guess.
  5. No datacenter. One ordinary computer runs Orbit. It can be yours.
  6. Nothing to explain. No Docker, ports, drivers or settings for the person using it.
Works today

What runs now.

  • Model fit from the Hugging Face name or link, with "unknown" when the name does not say.
  • Host program for your machine: heartbeat, runs the model with llama.cpp, relays the chat, stops the model at the end.
  • It only dials out, so it works behind a home router with nothing to configure.
  • Chat from any browser, sealed between the browser and your machine: ECDH P-256, HKDF, AES-256-GCM.
  • A session ends on its own when the machine stops answering.
  • The full loop ran on real hardware: a Radeon RX 580 with 8 GB.
Not built yet

Next, in order.

  1. Fingerprint check. The browser and your machine show the same short code, so a relay cannot swap keys unseen.
  2. Host program installs like an app on Windows, Mac and Linux.
  3. Streamed replies through the sealed relay.
  4. More than one model at a time, one per machine.
  5. Direct browser-to-machine link, with the relay as fallback.

The build order is in docs/NEXT.md.

What the sandbox is.

This address runs the real Orbit code in sandbox mode, so anyone can walk the loop without a GPU. The fit check, the session clock and the key exchange are the real code paths. These parts are not real:

  • The machines are simulated. No model runs. Replies are scripted and say so.
  • The simulated machine runs on the same server as the relay, so the sandbox shows how sealing works, not the privacy it gives when the machine is your own.
  • You enter as a guest. No email or password is asked for or kept. Everything is wiped often.
