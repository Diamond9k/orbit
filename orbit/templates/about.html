Why is it free?

People self-host to stop paying for something that runs on their own machine, and to keep their data. A fee would contradict that. Orbit is a passion project, not a business.

What can the relay see?

The relay passes messages between your browser and your machine. It sees a sealed envelope: its size and its time. It also sees which model you ran and for how long. It deletes the envelopes when the session ends.

One gap is open. Both keys travel through the relay, so a dishonest relay could swap them. Nothing checks for that yet. Run the relay yourself to close the gap today. A fingerprint check is next.

What works today?
  • The fit check, from a Hugging Face name or link.
  • The host program: it runs the model with llama.cpp and only dials out.
  • Sealed chat from any browser: ECDH P-256, HKDF, AES-256-GCM.
  • The full loop ran on real hardware: a Radeon RX 580 with 8 GB.
What is next?
  1. Fingerprint check, so a relay cannot swap keys unseen.
  2. Host program that installs like an app.
  3. Streamed replies.
  4. More than one model at a time.

How do I run it myself?
git clone {{ repo_url }}.git
cd orbit
python3 -m pip install -r requirements.txt
python3 -m orbit

Then open http://localhost:8000. Python, FastAPI, SQLite. No build step.

What is this sandbox?

The real Orbit code with simulated machines. No model runs, and replies are scripted. The simulated machine runs on the relay's own server, so the sandbox shows how sealing works, not the privacy of your own machine. You enter as a guest. Nothing is kept.
