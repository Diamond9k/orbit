Three roles

A broker, not a middleman.

User
Someone who wants to run an open model. A web browser. Nothing to install.
Host
Someone with an idle GPU. The host program dials out to Orbit, so it works behind a home router. Models run here. Paid for use, never for listing.
Orbit
The machine list, the booking, the ledger. Every money movement is rows that sum to zero. Orbit needs no GPU and runs on one ordinary computer.
